# Proposal: let each of us edit our own logs

Feedback covered: `45a7ec17-9d09-4b14-8104-ed6978ebc042` (Bindu, status new)
"Add an option to edit our own individual logs"

Status: DRAFT ONLY. Not merged to main. Apps Script NOT deployed. Needs Anirban's approval in the app.

## Change 1: backend (apps-script/Code.gs)

Add an `updateEntry` action. It only lets the writer change a row whose `who` matches the `who` sent in the request, so each person can edit only their own pages. It never touches the passcode, owner PIN, or owner controls.

Proposed addition to the `switch` in `doPost`:

```js
case "updateEntry": return json_(updateEntry_(d));
```

Proposed new function:

```js
// Edit one of our own log pages. Only the writer named on the row can change it.
function updateEntry_(d) {
  if (WHO.indexOf(d.who) < 0 || !d.id) return { error: "bad_request" };
  const sh = SpreadsheetApp.getActive().getSheetByName("Entries");
  const v = sh.getDataRange().getValues();
  const h = v[0];
  const idCol = h.indexOf("id"), whoCol = h.indexOf("who");
  for (let i = 1; i < v.length; i++) {
    if (String(v[i][idCol]) !== String(d.id)) continue;
    if (v[i][whoCol] !== d.who) return { error: "not_yours" };
    const row = {};
    h.forEach((k, j) => row[k] = v[i][j]);
    const mood = Number(d.mood);
    if (mood >= 1 && mood <= 5) row.mood = mood;
    if (["none", "small", "big"].indexOf(d.fight) >= 0) row.fight = d.fight;
    if (["yes", "no", "na", ""].indexOf(d.pauseUsed) >= 0) row.pauseUsed = d.pauseUsed;
    TEXT_FIELDS.forEach(f => { if (d[f] !== undefined) row[f] = String(d[f] || "").slice(0, 4000); });
    row.updatedAt = new Date().toISOString();
    sh.getRange(i + 1, 1, 1, h.length).setValues([h.map(k => row[k] === undefined ? "" : row[k])]);
    return { ok: true };
  }
  return { error: "not_found" };
}
```

Note: `updatedAt` is not in the `TABS.Entries` list, so either add it to that list or drop that line. The safer choice is to drop it for this first version.

Also note: the passcode is shared by both of you, so this check relies on the `who` the app sends. It is a convenience guard, not a security boundary. That matches how the rest of the app already works.

## Change 2: frontend (index.html)

Show an "Edit" button on a log page only when `e.who` equals the person currently selected in the app (`#who`). Tapping it opens the existing Log form pre-filled with that page's values. Saving calls `call("updateEntry", { id, who, mood, fight, pauseUsed, trigger, felt, needed, change, appreciation, other })` and then runs `refresh()`.

The button is placed in `renderHist()` next to the `.top` row. Pages by the other person show no button.
